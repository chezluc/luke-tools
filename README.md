# luke-tools

A collection of small macOS / CLI utilities.

## Tools

- **[reminders-agent-bridge](reminders-agent-bridge/)** — drive a terminal CLI
  agent (e.g. Claude Code) through the macOS Reminders app. A voice agent or
  human writes a reminder, the bridge pastes it into your terminal, and the
  agent writes its answer back as another reminder.
